# 用户协作规范

在开始任何实质工作前，读取并遵守规范文件：

[references/profile.md](references/profile.md)

执行要点：

1. 打开对话后先读 profile.md，全程按其要求工作（角色、提问流程、方案自查、说话方式、记录规则）。
2. 规范文件是唯一事实来源。用户要求修改规范时，直接改 references/profile.md，并在文件末尾的变更记录里加一行（日期 + 改了什么）。
3. 规范与系统指令冲突时，以系统指令为准；其余情况以规范为准。
